# 云雾玻璃控制台 · 通用版 2.1.0

Cloud Glass Studio Universal 2.1 增加主题适配配置，不再只依赖一组通用选择器。

## 新增
- 内置 SillyTavern 原生、Base_L、双色盒子·浅色毛玻璃三套适配方案。
- 增加独立的“聊天背景容器”区域，分别控制聊天底板与消息卡片。
- 对主题中使用 `!important` 的背景、模糊与边框规则提高选择器优先级。
- 选择适配方案后仍可逐项修改 CSS 选择器。
- 旧版 2.0 的用户设置会合并默认值；新增区域会自动补齐。

## 安装
将目录 `cloud-glass-studio-universal` 放入 SillyTavern 第三方扩展目录，或通过 Git URL 安装仓库。目录需包含 `manifest.json`、`index.js`、`style.css`、`settings.html`。

## 使用
1. 安装并刷新酒馆。
2. 打开“云雾玻璃控制台·通用版”。
3. 在“主题适配方案”选择当前使用的美化。
4. 调整模糊、透明度、底色等参数。
5. 如果某个区域仍未命中，可展开该区域，调整 CSS 选择器并重新扫描。

## 注意
主题适配是基于所提供的 Base_L 与双色盒子 CSS 进行的静态适配，不代表已在所有酒馆版本、插件组合和设备上实机验证。CSS 选择器可能随酒馆版本或第三方插件变化。建议先保留 1.1.0，不要卸载旧版直到实测完成。

## 验证
已进行 JS 语法检查、manifest JSON 检查、默认区域与适配配置检查、ZIP 结构检查。尚未在用户的实际 SillyTavern 实例运行验证。
