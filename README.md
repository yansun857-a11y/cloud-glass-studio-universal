# 云雾玻璃控制台 2.2.0

简洁控制面板 + 通用主题适配 + 自定义模板。

## 功能
- 毛玻璃模糊、玻璃透明度、玻璃底色、顶部与底栏透明度
- 字体、字号、正文/次要/引用文字颜色
- 通用、Base_L、双色盒子三种内置适配方案
- 四个初始模板，可无限新增、应用、删除自定义模板
- 自动保存到 SillyTavern 扩展设置

## 安装
将本目录文件覆盖 GitHub 仓库中的同名文件，保持目录名 `cloud-glass-studio-universal` 不变。

## 注意
模板保存在当前酒馆实例的扩展设置中，不会自动同步到其他设备或酒馆实例。适配方案和模板参数相互独立。
