# 云雾玻璃控制台 · 通用版 2.0.0

Cloud Glass Studio Universal 是独立于旧版 1.1.0 的通用适配原型。它通过可配置 CSS 选择器识别 SillyTavern 界面区域，再将统一的玻璃外观应用到匹配元素。

## 当前功能
- 全局玻璃参数：模糊、透明度、底色、饱和度、边缘、阴影、圆角。
- 五类区域选择器：聊天消息、顶部栏、底部输入区、弹出菜单、设置面板。
- 每个区域可独立启用/停用并修改 CSS 选择器。
- 监听页面新增元素，弹出菜单等动态元素可在出现后重新匹配。
- 五套预设：晴空、森林、玫瑰、午夜、原生/关闭。
- 可选文字排版覆盖，默认关闭。
- 设置自动保存到独立扩展设置命名空间 `cloud_glass_studio_universal`。

## 安装
将整个目录放入 SillyTavern 的 `public/scripts/extensions/third-party/cloud-glass-studio-universal/`，并按酒馆版本支持的方式加载本地第三方扩展。目录必须包含 `manifest.json`、`index.js`、`style.css`、`settings.html`。

## 适配说明
默认选择器针对常见 SillyTavern 原生界面结构提供起点，不保证覆盖所有主题或第三方插件。主题重写了 DOM 时，需要在扩展设置中替换对应区域的 CSS 选择器。选择器必须是有效 CSS selector；多个选择器可用逗号分隔。

## 安全与边界
扩展只把 `data-cgs2-region` 标记加到匹配元素，并由随包 CSS 施加外观变量；不会执行用户输入的代码，也不会改写页面布局或交互逻辑。选择器无效时会在控制台记录警告。部分主题使用高优先级背景图、伪元素或内联样式时，可能无法完全呈现玻璃效果。

## 验证状态
2.0.0 是第一版通用适配原型。已进行静态语法与包结构检查，尚未在多种 SillyTavern 主题和第三方插件组合中完成实机兼容性测试。
